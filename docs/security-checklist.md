# Printable Security Checklist

Print this page and check off each item as you complete it. Keep it with your important papers.

---

## Password Manager Setup

- [ ] Choose a password manager (Bitwarden, 1Password, Apple Keychain, etc.)
- [ ] Install the app on your phone and computer
- [ ] Install the browser extension
- [ ] Create a strong master password (passphrase, 4+ random words)
- [ ] Write your master password on paper and store it safely
- [ ] Save your recovery code / emergency kit (printed, not digital)
- [ ] Import or add your existing logins
- [ ] Turn on two-factor authentication for your password manager

---

## Two-Factor Authentication (2FA)

- [ ] Email account (most important — start here)
- [ ] Bank and credit card accounts
- [ ] Phone carrier account
- [ ] Password manager account
- [ ] Social media accounts
- [ ] Shopping accounts (Amazon, etc.)
- [ ] Save backup codes for each account (printed, not digital)

---

## AI-Assisted Security Review

- [ ] Pick one account to review with AI help
- [ ] Ask AI to walk you through 2FA setup for that account
- [ ] Review any suspicious emails with AI (remove personal info first)
- [ ] Create a strong passphrase with AI inspiration (then customize it)
- [ ] Repeat for remaining accounts, one at a time

---

## Ongoing Habits

- [ ] Use unique passwords for every account (let your manager generate them)
- [ ] Never reuse passwords across sites
- [ ] Check breach alerts from your password manager
- [ ] Review account security every 6 months
- [ ] Keep backup codes in a safe, accessible place

---

## Quick Reference

| If you... | Then... |
|-----------|---------|
| Forget your master password | Use your recovery code |
| Lose your phone | Use backup codes to log in, then set up 2FA again |
| Suspect a breach | Change that password immediately, check other accounts |
| Get a suspicious email | Don't click links. Ask AI or visit the site directly |

---

**Remember:** You don't have to do this all at once. One account at a time is fine.
